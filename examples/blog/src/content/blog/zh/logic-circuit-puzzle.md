## 一、核心逻辑门组件原理拆解

在游戏中，开关开启代表高电平 `1`，关闭代表低电平 `0`。逻辑门接收输入信号，并根据特定的规则输出 `0` 或 `1`：

### 1. 🤝 与门 (AND Gate) — “两个都要满足”
* **逻辑公式：** 只有当**所有输入开关都为 1** 时，输出才为 1；只要有一个开关为 0，灯泡就会熄灭。
* **现实类比：** 银行保险箱需要两把钥匙同时转动才能打开。

### 2. 🔀 或门 (OR Gate) — “只要一个就可以”
* **逻辑公式：** 只要**任意一个输入开关为 1**，输出就会变成 1；只有当所有开关都是 0 时，灯泡才灭。
* **现实类比：** 前门和后门的铃铛，只要按响任意一个，屋里的铃声就会响起。

### 3. 🔄 非门 (NOT Gate) — “唱反调的反相器”
* **逻辑公式：** 把输入信号颠倒！输入为 1 时输出 0，输入为 0 时输出 1。
* **现实类比：** 自动感应夜灯：白天有光（输入 1）时灯灭（输出 0），晚上没光（输入 0）时灯亮（输出 1）。

### 4. ⚡ 异或门 (XOR Gate) — “不一样才触发”
* **逻辑公式：** 两个输入信号**状态不一致**（一个 0 一个 1）时输出 1；如果状态相同（都是 0 或都是 1），则输出 0。
* **现实类比：** 楼梯上下楼的双控开关。

## 二、通过闯关培养三大编程逻辑

1. **条件逻辑（Conditional Thinking）：** 深入理解“如果……并且……”（IF... AND...）与“如果……或者……”（IF... OR...）的结构，这是编写所有软件程序的核心逻辑。
2. **信号逆向推理（Reverse Reasoning）：** 当终点灯泡没有亮起时，孩子需要从输出端往回倒推，找出是哪一个逻辑门或开关的信号阻断了电路。
3. **硬件与数字电路启蒙：** 为后续学习 Scratch 硬件编程、Arduino、树莓派（Raspberry Pi）乃至 CPU 架构打下坚实的认知基础。
