一、三大核心 C 语言基础概念
1. 📦 变量（Variables）—— “存储数值的小仓库”
在代码中，我们需要记住主角的血量和金币数。C 语言用 int（整数类型）来定义它们：

int hp = 100;   // 声明一个名为 hp 的整数变量，初值为 100
int gold = 10;  // 声明一个名为 gold 的整数变量，初值为 10

当主角受到伤害或获得金币时，我们只需要对变量进行加减计算即可。

2. 💬 输入与输出（printf & scanf）—— “人机交互的桥梁”
printf("...")： 让控制台在屏幕上打印出文字和剧情。

scanf("%d", &choice)： 让程序静静等待玩家在键盘上输入数字（如输入 1 或 2），并把输入的数值保存在 choice 变量中。

3. 🔀 条件分支（if - else）—— “剧情的选择岔路口”
这篇冒险的核心！程序根据玩家在 scanf 中输入的选项，决定走向哪一段剧情：

if (choice == 1) {
// 如果玩家按了 1，走向左边的通道（遭遇喷火龙）
printf("你遇到了喷火龙！\n");
} else if (choice == 2) {
// 如果玩家按了 2，走向右边的通道（发现金币宝箱）
printf("你找到了神秘金币宝箱！\n");
} else {
// 如果玩家按了其他数字，提示输入错误
printf("输入无效！\n");
}
